# Early Portfolio Experiment

An early frontend learning project using HTML, CSS and JavaScript. The current portfolio work is in [akash-portfolio](https://github.com/razesoni/akash-portfolio).

## Run locally

From the repository root:

```bash
python -m http.server 8080
```

Open http://localhost:8080. No application backend is included. Third-party images, music and other assets retain their respective rights.

For data science and machine learning work, see [my GitHub profile](https://github.com/razesoni).
